EmotionalGeologyパート
======================

ユーザに「起こった出来事」「その時の感情」「出来事の重要さ」を質問し、日付と合わせて永続的に記憶する。日付、出来事、感情、重要さの4つ組をstratumと呼び、これを毎日1-2層蓄積することをこのパートの第一の目標とする。

stratum={
    data: 日付,
    event: ユーザが報告した出来事,
    emo: eventについてのユーザの感情,
    importance: eventの重要さ
}

またstratumを分析することで「最近あった重要な出来事の現状」「最近 emo X が増えた理由」など追加の質問ができる。これをgeologyと呼び、geologyを永続的に記憶することが第二の目標である。

geology={
    type: 分析方法,
    event: 出来事,
    emo: その出来事についての感情,
    importance: eventの重要さ,
    currently: 現状
}

上述の説明は固く見えるが、実際にはユーザとの自然なやり取りとしてよく見られるものである。
```
bot: 今日は楽しいことあった？
user: 今日はみんなでカラオケにいったよ！
bot: どれくらい楽しかったの？
user: すごく！
bot: そっかー！いいね！
```

## 心理学的側面
* ユーザに自身の感情体験を開示してもらうこと、またその重要性を自ら説明してもらうことは自己についての認知を深める効果が期待できる。
* チャットボットがユーザの感情体験について興味を持ち、それを覚えていて後日質問することはユーザのチャットボットに対する愛着につながる
* ユーザの感情体験の傾向について経時的な変化を追跡できる。それがよりポジティブなものに変わっていくことはチャットボットの具体的な効果である。
* 日頃無表情なアバターに明示的に表情をつけられる。


## アルゴリズム
基本的には slot filling である。
一日にstratum,geology合わせて1-2個を生成する。
生成直後は下記のように未代入の値をundefinedとする。
stratum={
    date:Date(),
    event: undefined,
    emo: undefined,
    importance: undefined
    }
ユーザに質問し、回答が得られた項目はそれを代入し、undefinedがなくなるまで質問を行う。
すべてのstratum,geologyが完成したらユーザにお礼を言う。
以降はユーザに聞かれたら記憶している内容を検索して返答を行う。

質問文の生成ルールは辞書(*.emogeology.json)に切り出してあとから変更できるようにする。

## データの保持
dexieJsでローカルに保存し、firestoreにも並行して保存する。最新版の維持などの扱いはEpisodeStorageに準ずる。

### emotion
emoはEpisodeStorageで利用したチャットボットのemoと同じ8種を用いる。

| emo	       | evnet質問                        |
|--------------|----------------------------------|
| joy          | 今日楽しかったことは？           |
| sadness      | 今日悲しかったことは？           |
| anger	       | 今日腹が立ったことは？           |
| fear	       | 今日不安だったことは？           |
| trust        | 最近信頼できると感じたことは？   |
| disgust	   | 嫌だなと思ったことは？           |
| anticipation | 楽しみにしていることは？         |
| surprise     | 意外だったことは？               |

さらに「すごく楽しかった」「少しだけ楽しかった」のような感情の強度も質問し、
返答から得た1-5の数値をimportanceとして記録する

またevent,emo,importanceの情報はパートから質問する前にユーザが発言する場合もある。

### event

ユーザが語った出来事・体験

自然言語のまま保存する。

### importance
ユーザ発言の中に含まれるキーワードを利用し、1-5の値を取り出す

```
1: ["あんまり", "すこしだけ", "微妙に"],
2: ["少し", "ちょっとだけ"],
3: ["普通", "まあまあ", "ちょっと", "当たり前"],
4: ["とても", "かなり", "だいぶ"],
5: ["超", "ものすごく", "めっちゃ", "すごく", "すごい"]
```
